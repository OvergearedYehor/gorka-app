<a id="features"></a>
## Возможности

- **Мобильный лист dnd5e:** обзор персонажа, избранное, особенности, инвентарь, заклинания, эффекты, биография и дневник.
- **Броски и чат:** проверки, навыки, атаки и урон через dnd5e; быстрый бросок костей и применение входящих карточек урона/исцеления.
- **Игровые действия:** выбор цели, передвижение токена, реакции и завершение хода.
- **Совместимость с автоматизацией:** relay на клиент мастера для Midi-QOL и связанных модулей; поддержка ручных физических бросков `pp-dice` на телефоне.
- **Мобильный режим:** полноэкранный интерфейс, быстрый показ сохранённого листа при загрузке и светлая/тёмная тема.

<a id="about-the-fork"></a>
## Авторство и совместимость форка

Gorka Pocket App — форк [Elfrey Pocket App](https://github.com/Elfrey/elfrey-pocket-app), созданного [Elfrey](https://github.com/Elfrey). Благодарим автора исходного проекта. В этом форке добавлены брендинг Gorka и дополнительные мобильные функции. Технический ID модуля (`elfrey-pocket-app`) сохранён для совместимости, а manifest и архив установки публикуются в релизах этого репозитория.

**Важно:** форк и оригинальный модуль имеют общий технический ID `elfrey-pocket-app`; не устанавливайте обе копии одновременно. Manifest форка ниже будет скачивать архив именно из релизов этого репозитория. Upstream Elfrey доступен отдельно по ссылке в следующем разделе.

<a id="installation"></a>
## Установка

### Установить этот форк

В Foundry откройте *Дополнения → Установить модуль*, вставьте manifest форка и нажмите **Установить**:

```text
https://github.com/OvergearedYehor/gorka-pocket-app/releases/latest/download/module.json
```

Foundry скачает актуальные `module.json` и `module.zip` из GitHub Releases. Затем включите **Gorka Pocket App** в мире. Для обновления используйте стандартную проверку обновлений модулей Foundry.

Если в репозитории ещё нет опубликованного релиза, ссылка станет доступна после первого релиза форка. До этого можно установить вручную: скачайте ZIP репозитория и скопируйте его содержимое в `Data/modules/elfrey-pocket-app`; `module.json` должен лежать непосредственно в этой папке. Не устанавливайте одновременно upstream и форк — у них общий ID.

### Установить оригинальный Elfrey Pocket App

Если вам нужен именно оригинальный проект, в Foundry откройте *Дополнения → Установить модуль* и используйте его manifest:

```text
https://github.com/Elfrey/elfrey-pocket-app/releases/latest/download/module.json
```

Этот адрес устанавливает upstream, **не форк Gorka**.

**Только для Foundry v14:** после установки нужно один раз запустить скрипт на компьютере (сервере), где работает Foundry. Повторите запуск после каждого обновления Foundry v14. Подробная инструкция — ниже.

На Foundry v13 второй шаг не требуется.

### Foundry v14: запуск скрипта установки

**Зачем.** Foundry v14 не отдаёт HTML-страницы из папки данных, поэтому страницу приложения нельзя открыть напрямую. Скрипт создаёт ссылку на папку модуля из папки *программы* Foundry, где такого ограничения нет. Запускать его нужно на том компьютере, где работает Foundry, и **повторять после каждого обновления Foundry** — обновление заменяет папку программы, и ссылка пропадает. Перезапускать Foundry после скрипта не нужно.

**Где лежит скрипт.** В папке модуля, внутри папки данных Foundry:

```
<папка данных Foundry>\Data\modules\elfrey-pocket-app\tools\install-v14.ps1   (Windows)
<папка данных Foundry>/Data/modules/elfrey-pocket-app/tools/install-v14.sh    (macOS / Linux)
```

Папку данных показывает сам Foundry: стартовый экран → *Configuration* (Настройки) → поле *User Data Path* (Путь к данным пользователя). Если вы её не меняли, она стандартная:

| ОС | Папка данных Foundry по умолчанию |
| --- | --- |
| Windows | `C:\Users\<имя пользователя>\AppData\Local\FoundryVTT` |
| macOS | `~/Library/Application Support/FoundryVTT` |
| Linux | `~/.local/share/FoundryVTT` |

Не путайте её с папкой *программы* Foundry (на Windows обычно `C:\Program Files\Foundry Virtual Tabletop`) — ту скрипт найдёт сам или спросит.

#### Windows

1. Откройте PowerShell **от имени администратора**: Пуск → наберите `PowerShell` → правый клик по найденному → *Запуск от имени администратора* (в Windows 11 подойдёт и Win+X → *Терминал (Администратор)*). Права администратора нужны, потому что Foundry обычно установлен в `Program Files`.
2. Окно откроется в папке `C:\Windows\System32` (или в вашей домашней папке) — это нормально. Переходить в папку модуля не нужно: скрипт запускается по **полному** пути. Скопируйте команду целиком, вставьте в окно (правый клик или Ctrl+V) и нажмите Enter:

   ```powershell
   powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\FoundryVTT\Data\modules\elfrey-pocket-app\tools\install-v14.ps1"
   ```

   Команда рассчитана на стандартную папку данных. Если у вас другая, замените путь в кавычках на свой, например `"D:\FoundryData\Data\modules\elfrey-pocket-app\tools\install-v14.ps1"`. Точный путь проще всего взять из Проводника: откройте папку `tools` модуля, правый клик по `install-v14.ps1` → *Копировать как путь* (в Windows 10 — правый клик с зажатым Shift), затем в PowerShell наберите `powershell -ExecutionPolicy Bypass -File ` и вставьте скопированное.
3. Скрипт сам ищет папку программы Foundry. Если не нашёл, он напишет `Путь до Foundry:` — введите папку, куда установлен сам Foundry (обычно `C:\Program Files\Foundry Virtual Tabletop`; у сборки на Node — распакованная папка, внутри которой есть `resources\app\public` или `public`), и нажмите Enter. Папку можно указать и сразу — добавьте в конец команды ` -Foundry "C:\Program Files\Foundry Virtual Tabletop"`.
4. Успех — строка `Готово: ... -> ...`. Окно можно закрывать, Foundry перезапускать не нужно.

Если что-то пошло не так:

| Сообщение | Причина и что делать |
| --- | --- |
| `Не удается найти путь ".\Data\modules\..."`, `Имя ".\Data\..." не распознано` (*The term '.\Data\...' is not recognized*) | Скрипт запущен относительным путём из чужой папки — обычно из `C:\Windows\System32`. Используйте полный путь, как в команде выше. |
| `Невозможно загрузить файл ... выполнение сценариев отключено в этой системе` (*running scripts is disabled on this system*) | Скрипт запущен без `-ExecutionPolicy Bypass`. Скопируйте команду выше целиком, а не только путь к файлу. |
| `Не удается найти путь "$env:LOCALAPPDATA\..."` — путь так и остался с `$env:` | Команда вставлена в командную строку (cmd), а не в PowerShell. Откройте PowerShell, как в шаге 1, или впишите путь целиком, без `$env:LOCALAPPDATA`. |
| `Не удалось создать ссылку ... запустите PowerShell от имени администратора` | Окно открыто без прав администратора. Закройте его и откройте заново, как в шаге 1. |
| `Папка Foundry указана неверно: ... нет public\` | Вместо папки программы Foundry указана папка данных (та, где лежит `Data\`). Нужна папка, внутри которой есть `resources\app\public` — обычно `C:\Program Files\Foundry Virtual Tabletop`. |

#### macOS / Linux

1. Откройте терминал: на macOS — Spotlight (⌘ Space) → «Терминал» или *Программы → Утилиты → Терминал*; на Linux — обычный терминал, а если Foundry работает на удалённом сервере — подключитесь к нему по SSH.
2. Выполните команду с полным путём к скрипту (переходить в папку модуля не нужно). Для стандартной папки данных:

   macOS:
   ```sh
   sh "$HOME/Library/Application Support/FoundryVTT/Data/modules/elfrey-pocket-app/tools/install-v14.sh"
   ```

   Linux:
   ```sh
   sh "$HOME/.local/share/FoundryVTT/Data/modules/elfrey-pocket-app/tools/install-v14.sh"
   ```

   Если папка данных другая (например, сервер запущен с `--dataPath=/home/foundry/data`), подставьте её: `sh /home/foundry/data/Data/modules/elfrey-pocket-app/tools/install-v14.sh`. Кавычки вокруг пути обязательны, если в нём есть пробел (как в стандартном пути macOS). На macOS путь можно не набирать: введите `sh ` и перетащите файл `install-v14.sh` из Finder в окно Терминала — путь вставится сам.
3. Скрипт сам ищет папку программы Foundry. Если не нашёл, он спросит `Путь до Foundry:` — введите папку, где лежит `public/`: у десктопного приложения на macOS это `/Applications/Foundry Virtual Tabletop.app/Contents/Resources/app`, у серверной сборки на Node — распакованная папка Foundry (внутри неё `resources/app/public`). Папку можно передать сразу, первым аргументом: `sh .../install-v14.sh /opt/foundryvtt`.
4. Успех — строка `Готово: ... -> ...`. Перезапускать Foundry не нужно.

Если скрипт завершился с `Permission denied` — папка программы Foundry принадлежит другому пользователю (например, `/opt/foundryvtt` под root). Повторите ту же команду, добавив в начало `sudo `.

<a id="player-launch"></a>
## Запуск игроками

Откройте обычную ссылку вашего Foundry на телефоне и войдите под своим игроком — модуль сам определит телефон и откроет приложение.

- **Добавить на экран «Домой»:** меню ⋮ в приложении → и оно будет запускаться на весь экран, как отдельное приложение.
- **Нужен полный клиент** (например, на планшете): меню ⋮ → *Полный клиент*.
- Мастеров приложение никогда не перенаправляет — они всегда попадают в обычный клиент.

<a id="usage"></a>
## Как пользоваться

Внизу — панель вкладок:

- **Обзор** — пункты здоровья (урон / исцеление / временные ПЗ), класс брони, характеристики, испытания, навыки, инструменты, состояния, утомление, концентрация, инициатива и отдых. В бою вместо инициативы появляется кнопка «Закончить ход». Сверху — переключатель преимущества/помехи, «быстрый бросок» (без диалога) и кому виден бросок.
- **Избранное** — то, что отмечено избранным на полном бланке персонажа: предметы, заклинания, навыки, ячейки заклинаний.
- **Особенности** — классовые особенности, черты, вид, предыстория; сгруппированы по типу действия.
- **Инвентарь** — предметы по категориям, экипировка и настроенность на магические предметы, контейнеры, поиск, валюта (в поле можно писать `+11` или `-11`, чтобы прибавить/потратить).
- **Заклинания** — ячейки заклинаний, подготовка заклинаний (кнопка «Подготовить» открывает полный список), фильтры (круг, школа магии, компоненты, концентрация, ритуал и т.п.).
- **Ещё** — Действия, **Передвижение** (восемь направлений на квадратной сетке), Биография (с редактированием), Дневник и Эффекты. Передвижение выполняется по одному шагу через подключённый клиент мастера; в Foundry v14 оно использует штатное клавиатурное движение, включая привязку к сетке, линейку и правила движения. Мастер должен смотреть сцену с ровно одним токеном персонажа. На гексагональной сетке эта функция пока недоступна. Здесь же, в меню ⋮ сверху — смена персонажа, *Полный бланк* (обычный бланк dnd5e), тема, диагностика и выход.

**Использование** предмета, заклинания или особенности — тап по иконке. **Тап по названию** открывает карточку с описанием и кнопками (бросок атаки, бросок урона, в чат и т.д.). Перед отдельным броском атаки выберите противника в списке: выбранная строка подсветится. После подтверждения выбора откроется штатное окно броска dnd5e на клиенте игрока — нажмите в нём кнопку броска. Отдельные броски атаки и урона выполняются на клиенте игрока и публикуются от его имени; мастер для них не нужен.

Штатный ручной способ бросков Foundry продолжает работать, если у игрока есть разрешение мастера и этот способ выбран в настройках костей на его клиенте.

Если в мире включён **Physical Play Dice (`pp-dice`)**, приложение загружает его на телефоне вместе с нужными зависимостями. Поэтому окно ввода физических результатов появляется прямо на устройстве, где игрок нажал бросок. В настройках модуля он также должен быть включён для игрока.

Выбранная цель и её КД передаются в карточку броска dnd5e, чтобы результат был привязан к выбранному противнику. Сам бросок остаётся на клиенте игрока, поэтому автоматизация сторонних модулей, не загруженных в приложение (например, Midi-QOL), для отдельного броска не запускается. Для такой автоматизации используйте применение предмета через relay (если включено) или полный клиент Foundry.

**Чат** — кнопка с облачком в шапке. Есть история, быстрый набор костей (тап по кости добавляет её в бросок, рядом — модификатор и преимущество/помеха; бросок уходит отправкой сообщения), а у карточек урона/исцеления от мастера — кнопки «Применить ко мне» / «Исцелить меня».

**Быстрый старт.** Приложение показывает бланк персонажа сразу, из памяти телефона, пока подгружается мир: вкладки листаются, описания заклинаний и предметов открываются. Сверху видна полоса — когда сохранены данные, какой шаг загрузки идёт и сколько это длится; действия и броски пока недоступны. Как только мир загрузился, бланк молча становится живым. При первом запуске приложение один раз объяснит это шторкой — её можно отключить галочкой «Больше не показывать».

**Тема** (светлая / тёмная / как в системе) — меню ⋮ → раздел «Тема».

<a id="automation"></a>
## Midi-QOL и автоматизация мастера

Если в мире включён **midi-qol**, использование предметов и заклинаний из приложения выполняется **на клиенте мастера** — так их обрабатывают midi-qol и всё, что построено поверх него (DAE, Chris's Premades…): броски атаки и урона, испытания целей, применение урона, эффекты, анимации. Управляется настройкой *Использовать предметы через клиент мастера* (Авто — пока midi-qol включён). Нужны мастер в сети и модуль **socketlib**.

- **Цели.** Карты на телефоне нет, поэтому перед использованием приложение показывает список целей — только тех существ, которых **видит токен персонажа** и которые **в радиусе** действия (по правилам midi-qol: reach, дальний бросок — с пометкой, стены). Вне радиуса — за кнопкой «Показать всех видимых». Имена НИП показываются так, как их видят игроки: поддерживаются **Hide NPC Names** и **Anonymous** — скрытое имя заменяется на «Неизвестное существо» (или заданное мастером). Сцена подписывается навигационным именем.
- **Реакции.** Когда НИП атакует персонажа, у которого есть реакция (Щит, внеочередная атака…), на телефоне всплывает «Реакция!» с обратным отсчётом.
- **Испытания и проверки**, которые midi-qol просит бросить игрока, бросаются на телефоне через штатный диалог dnd5e — независимо от того, каким модулем стол обычно собирает броски (Monk's Token Bar, Flash Rolls, Epic Rolls): для игроков в приложении midi-qol возвращается к своему собственному запросу, остальные продолжают пользоваться привычным модулем.
- **Диалоги Chris's Premades**, адресованные игроку («применить особенность?», выбор цели), открываются на телефоне.

- **Круг заклинания и расходники** выбираются на телефоне — открывается обычный диалог использования dnd5e (апкаст, расход слота или зарядов, концентрация), и выбор уходит мастеру вместе с запросом.

Ограничения: область (шаблон) размещает мастер — карта есть только у него; диалоги Chris's Premades пересылаются игроку, начавшему использование, но если он не ответит за две минуты или двое кастуют одновременно — открываются у мастера; диалоги самого midi-qol (метамагия, бонусы) остаются у мастера.

<a id="gm-settings"></a>
## Настройки мастера

*Настройки модулей → Gorka Pocket App*:

- **Выбрать игроков** — закрепить конкретных игроков за приложением: они попадут в него с любого устройства.
- **Отправлять телефоны в мобильное приложение** — Авто (по умолчанию) / Всегда / Никогда.
